# Arena PvP (working title)

An original fantasy PvP game inspired by the arena and battleground modes of classic MMOs: 1v1, 2v2 and 3v3 arenas and 10v10 battlegrounds, 13 classes and 39 specializations, talent trees, and a stylized, darker art style.

- Engine: Godot 4.7 (GDScript), dedicated headless server at 60 ticks per second.
- Art: every model built by Python scripts in headless Blender 4.5.
- Built by an AI model working through `BACKLOG.md` in a fixed build loop. See `CLAUDE.md`.
