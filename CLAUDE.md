# Instructions for Claude working in this repository

This repository builds an original, arena-focused fantasy PvP game (1v1, 2v2 and 3v3 arenas, 10v10 battlegrounds) in Godot 4.7, with every 3D asset generated by headless Blender scripts.

Read these before doing anything else, in this order:

1. `docs/DESIGN.md` — the full design and the source of truth.
2. `BACKLOG.md` — the ordered work list, including environment notes.
3. `DECISIONS.md` and `KNOWN_ISSUES.md` — what has been decided and what is open.

Then work in the build loop from DESIGN.md, one backlog item at a time:

1. Pick the top item not marked done or blocked, and mark it `[doing]`.
2. Confirm or sharpen its acceptance criteria.
3. Implement it. Prefer data changes over code changes.
4. Run `tools/check_all` (once it exists). Fix failures before continuing.
5. Look at the result: screenshots, Blender preview sheets, logs. Use the Read tool on images.
6. Commit, add a CHANGELOG.md entry, mark the item `[done]`, and add any follow-up items to BACKLOG.md.

After 3 failed attempts on one item, write it up in KNOWN_ISSUES.md, split it, and move on. Every 10 items, run the review pass from DESIGN.md.

Hard rules:

- Original IP only. No names, lore, icons or assets from World of Warcraft or any other existing game.
- All gameplay content lives in `/data` as JSON. No per-class code branches.
- Record every choice DESIGN.md leaves open in DECISIONS.md. Ask the human before changing the engine, the network model or the art style.
- Never loosen acceptance criteria silently.
